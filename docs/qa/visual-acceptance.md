# 视觉验收记录

验收日期：2026-09-20。全部视觉设计、界面实现与截图复核由主智能体完成，工程子任务使用 GPT 5.6 Terra Max。

## 参考与实现

四张参考图的细线坐标、椭圆轨道、方形定位节点、冷色色块与拆解构图，被转化为原创 SVG 图版与网站排版。没有使用参考图中的人物、字幕或整图作为页面内容。首页以完整标语为主标题，右侧轨道图版使用钴蓝、雾蓝、冰青与深蓝灰；文章阅读区域保持纸灰和石墨色，内容图片保留原色。

标题采用思源宋体 Medium 字形，经授权允许的重命名、WOFF2 压缩与 Unicode 分片处理。文章正文使用系统中文无衬线，桌面阅读宽度约 760px。文章卡片具有半透明中性底、细高光边缘和轻微模糊；不支持 backdrop-filter 时退化为稳定底色。

## 三轮复核

1. 第一轮确定首页比例、左右构图、卡片层次与移动端首屏节奏。
2. 第二轮检查前后台接通后的文章、成员、模块编辑及各类状态，修正成员数据适配、移动排版与编辑交互。
3. 最终复核加深辅助文字以满足对比度，调整 768px 后台为可展开侧栏，并重查公开版本、表格公式、长标题与无封面文章。

## 可访问性与动效

`scripts/accessibility-qa.mjs` 对十个主要前后台页面运行 axe 的 WCAG 2 A/AA 与 WCAG 2.1 AA 规则，最终 `accessibility.json` 的 violations 均为空。这是自动化规则检查结果，不等同于完整辅助技术认证。

浏览器验收还检查了跳到正文的键盘入口、移动导航展开/关闭、暂停动画，以及系统减少动态效果设置。对话框提供焦点约束、Esc 关闭与焦点返回。首页图版离屏暂停，移动端简化运动；正文不参与动态变形。

## 复现

先启动本地应用与数据库，再执行：

```bash
QA_ROUND=final node scripts/visual-qa.mjs
node scripts/accessibility-qa.mjs
pnpm test:e2e
```

脚本默认使用 `.data/dev-admin.json` 中的本地验收账号；通过 `E2E_BASE_URL`、`E2E_ADMIN_FILE` 可以指定独立环境。生产环境测试详情与持久化、恢复结果分别见 `validation.md` 和 `storage-validation.md`。
