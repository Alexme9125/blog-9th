# 邮件、订阅、入社与特殊页面验收

验收日期：2026-09-26。共享功能适用于 `main` 和 `9th-Anniversary`，不改变两分支的默认首页版本。

## 功能与数据验证

- `pnpm typecheck`、`pnpm lint`、`pnpm build` 通过。
- `pnpm test`：19 个测试文件，129 项通过。新增用例覆盖 SMTP 加密、密码保留/清除、权限、密钥轮换、投递去重、并发领取及失效租约恢复；订阅确认、来源校验、限流、申请资料隔离与删除、发布事务回滚和撤回；特殊页面草稿隔离、并发修改及媒体访问权限。
- 邮件传输测试使用本机 TLS SMTP 服务，验证真实连接及投递；数据库集成测试覆盖真实 PostgreSQL。
- 本地已有数据库执行迁移成功。另在隔离库验证早期开发结构的 `expires_at NOT NULL` 经 `0005` 变为可空，保证退订链接不因过期而失效。
- 浏览器实际操作结果见 [workflow.json](workflow.json)：关闭自动推送后发布不创建文章邮件；手动预览并确认创建一条任务，重复操作不会重复投递；开启自动推送后首次发布创建任务，修改重发不重复。
- 同一浏览器验收包含订阅与申请的 GET 确认页只读、显式提交才确认、申请人和社团两份申请邮件入队、后台审核，以及特殊页面保存草稿不影响公开页面、发布后生效。
- 浏览器流程只使用 `example.test` 地址和回环 SMTP 配置，未向真实收件人发信。测试结束后恢复邮件设置、特殊页面和临时资料。浏览器入队验收与本机 TLS 投递测试是分开的；实际邮箱服务商认证、DNS 和送达率需部署后使用管理员自己的邮箱验证。

- 公开页面 `/about`、`/privacy`、`/subscribe`、`/join` 检查 1440、768、390、360 px，均无页面横向溢出。

## 部署交接

本次需要数据库迁移；不能仅重建应用而跳过 `migrate`。SMTP 默认关闭，管理员填写并启用后才开放表单和发送邮件。自动推送默认关闭、手动推送默认允许，可独立设置。生产操作及密钥备份/轮换见 [SMTP 配置](../../SMTP配置.md)。本次没有连接或修改公网生产服务器。
