# 九周年转场残帧修复与逐幕配色

日期：2026-09-22。主智能体负责视觉实现及截图检查，GPT 5.6 Terra Max 子智能体进行只读时序审查。

## 修复

原先在转场结束的 RAF 回调中先把 `--phase` 归零，再等待 React 隐藏旧场景，导致仍为 `leaving` 的旧装饰短暂恢复到完全不透明。浏览器记录在三次边界均复现此问题，见 [修复前记录](before-boundary-probe.json)。

现在跨场景时保留上一完整画面，直到 React 提交新的场景状态，再在 layout effect 中同步写入相位、过渡图形、底色与数字渐变。后续 RAF 也受已提交场景键约束。暂停、重播、减少动态效果沿用同一提交顺序。[修复后记录](after-boundary-probe.json) 未发现残帧。

- Chrome、WebKit 均通过 `e2e/anniversary.spec.ts`。各捕获三次相位归零，残帧数均为零；采样中数字主色单通道最大步进为 2/255，详见 [浏览器数据](browser-probes.json)。测试使用浏览器实际 DOM/CSS 与 Playwright 时钟，不是视频逐像素比较。
- 检查过渡中间态、四种不同数字颜色、终态继续等待 60 秒、重播、转场中暂停、减少动态效果开关，以及页面无运行时错误。
- 主智能体检查四幕与过渡桌面截图，以及 768、390、360px 截图；无横向溢出，数字、周年文字与控制按钮布局正常。
- 单元与数据库集成测试：11 文件、72 项通过；新增颜色边界连续性、渐变中点及最终高光测试。
- 类型检查与 lint 通过；生产构建通过。现有媒体模块仍有两项动态文件系统追踪提示。
