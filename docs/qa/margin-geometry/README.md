# 主页与工作台的边缘线条

按用户要求，在主页文章区域和 `/admin` 工作台的留白处增加错位矩形、开放折线、菱形及定位短线。中段使用现有中性灰，主要线条透明度为 15%–22%，辅助线更淡，靠近内容时渐隐；手机端缩小并减少图形。

装饰由共享 SVG 与 CSS Modules 绘制，无动画、无事件处理。装饰层独立裁切，设置 `aria-hidden`、`focusable="false"` 和 `pointer-events: none`。层级调整只用于主页文章段及工作台自身，不改后台公共外壳，保留其他管理页面的弹窗层级。

验证：

- Chrome 下检查主页文章区及工作台的 1440、768、390、360 px 截图，由主智能体逐一复核。
- WebKit 下补充 1440、390 px 检查，渐隐蒙版正常，无横向溢出或运行时错误。
- 页面无横向溢出、仍各有一个 `main`，浏览器无运行时错误。
- 文章卡片可跳转，手机后台菜单可打开并进入文章管理。
- 类型检查与 ESLint 通过。

截图及浏览器检查数据存于本目录。
