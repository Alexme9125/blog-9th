## 测试覆盖

- 管理员创建账号、作者首次强制改密、写作、提交审核、发布、修订旧稿、重新审核发布、撤回和永久删除。
- 作者只能修改自己的内容；不能发布文章、管理页面/成员/设置；关闭公开注册。
- 同时降权管理员时仍保留最后一位管理员；停用账号、重置密码和自行改密后旧会话失效。
- 已发布内容在草稿修改、审核期间仍保持旧快照。撤回后搜索、RSS、sitemap 不再暴露该文章。
- CAS 版本检查阻止并发保存覆盖，修订可恢复为草稿。
- 验证实际图片格式、拒绝恶意文件；草稿媒体拒绝匿名读取，发布后可读，撤回后恢复私密。仅存在于旧修订中的图片同样受到删除保护。
- Tiptap 标题、表格、行内/块级公式与封面保存后可公开渲染；严格结构校验拒绝任意 HTML 和未知字段。
- 五类页面模块的添加、排序、保存、重新加载与发布；固定导航保护；成员资料排序、维护与账号独立。
- 登录失败反馈、键盘跳转、移动导航、动画暂停与减少动态效果。
- 额外浏览器检查验证超大图片在发送前被拦截、代理返回非 JSON 的 503 时显示中文提示；没有写入测试媒体。

浏览器流程通过界面实际创建和编辑内容，使用匿名浏览器上下文验证公开边界。测试内容使用随机后缀，完成后清理对应文档、临时账号和上传图片。生产登录测试按保护窗口间隔运行，没有关闭登录限流。
