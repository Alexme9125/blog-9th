## 首次上线仍需配置

1. 选择要部署的分支，在目标服务器安装 Docker Engine、Buildx / BuildKit 与 Docker Compose。
2. 复制 `.env.example` 为权限 `0600` 的 `.env`，替换全部密码与密钥占位符，设置正确的域名和 `SITE_EDITION`。
3. 设置 DNS，放通 TCP 80/443，再运行 `docker compose up --build -d`。
4. 执行 `docker compose --profile bootstrap run --rm bootstrap` 创建首个管理员并设置密码，从同一 HTTPS 域名登录。之后在后台创建的成员账号首次登录时必须修改临时密码。
5. 在生产内容写入前确定备份保留位置，定期将备份复制到独立存储并演练恢复。

具体命令见 [域名与部署指南](域名配置与部署.md)、[版本切换](anniversary-editions.md) 和 [README](../README.md)。本次准备与验证不等于已向公网服务器部署。
